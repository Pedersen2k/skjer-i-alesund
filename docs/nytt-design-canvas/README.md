# kaskjerda.no – nytt design (Claude Design-lerret, 12. nov 2026)

Kopi av lerretet https://claude.ai/artifact/AsauyA143yVYigphLECRrV, laget utenfor prosjektet «Kaskjerda.no Veien videre». Lagret for senere gjennomsyn; ingenting er valgt eller bygget.

- `project/Main.dc.html`: seks logoforslag (01 Brosundet, 02 Jugendtårnet, 03 Utsikten fra Aksla, 04 Molja fyr, 05 418 trapper til Fjellstua, 06 Snakkebobla).
- `project/A-Fjordglass-*.dc.html`: A Fjordglass (mørk glassdesign med skyline), mobil og PC.
- `project/B-Jugend-*.dc.html`: B Jugendpastell, mobil og PC.
- `project/C-Aksla-*.dc.html`: C Solnedgang fra Aksla, mobil og PC.
- `project/canvas.json`: oppsettet på lerretet.

Filene er Design-komponenter (`.dc.html`) og trenger Claude Design-lerretet for å vises; åpne lenken over for å se dem.
